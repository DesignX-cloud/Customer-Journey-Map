### 4.1 HTML 與 SVG 的協作方式

- 03 使用 2400 × 1505 共用座標系。
- 畫布 ID 為 `consultation-flowchart`，`data-nodes="./nodes.json"`。
- `.flowchart-container` 是可雙向捲動、可取得焦點的視窗。
- `.flowchart-surface` 提供縮放後的捲動範圍；`.flow-canvas` 使用左上角作為縮放原點。
- HTML 承載標題、泳道、節點、標籤與備註；SVG 承載連線。
- `<use href="./flowchart.svg#consultation-connections">` 引用外部 SVG 群組。
- 22 個節點具有唯一 ID、`data-flow-node` 及固定位置／尺寸。
- 整個畫布一次縮放，使節點與連線不會分別縮放而產生偏移。

### 4.2 共用 JS 的現有行為與硬編碼

| 項目 | 目前行為 |
|---|---|
| 畫布選取 | `document.getElementById("consultation-flowchart")`；找不到便結束 |

### 5.3 連線與流程判讀

- 主線：確認預約 → 場勘 → 記錄需求 → 說明服務建議 → 服務條件判斷。
- 跨泳道：客戶確認安排、參與場勘、補充資訊、評估合作條件，與專員節點連接。
- 條件符合時交由客戶評估；後續有通往簽約階段的路徑。
- 條件不符／無法調整時，連至是否願意繼續洽談／簽約的判斷。
- 虛線包含取消／未到、條件不符、暫不願意，以及有疑慮時補充說明、重新確認的分支。
- SVG 以 `#3589A5` 描邊表達連線；虛線實際由許多短路徑片段組成，並非依靠 `stroke-dasharray`。
- SVG 沒有語意上的邊資料。流程關係由幾何與視覺判讀取得，不應宣稱已取得機器可讀的完整流程圖模型。
- 應完整保留現有路徑，不重新生成、拉直、重排或改變連線。
