# 客戶旅程與流程知識庫
互動式客戶旅程流程圖及培訓資料

## 📌 專案簡介

本專案以**客戶旅程（Customer Journey）**為核心，整理從「需求產生」到「關係維護」的完整服務流程，涵蓋 12 個階段。

透過視覺化流程圖與對應的教學資源，協助使用者快速理解各階段的服務內容、角色分工、作業流程及常見應對情境。

希望將原本分散的流程資訊與教育訓練內容，逐步整合成容易查找、理解與學習的知識庫。

## 🔗 專案入口

### ① 客戶旅程互動流程圖

**[開啟客戶旅程流程圖](https://designx-cloud.github.io/Customer-Journey-Map/index.html)**

以客戶旅程的 12 個階段為架構，逐步建立各階段的服務流程與教學內容。

**主要功能：**
- 瀏覽客戶旅程各階段的服務流程。
- 透過泳道流程圖了解不同角色的作業與互動。
- 點擊流程節點上的連結圖示，查閱對應的教學資料。
- 使用縮放及捲動功能，閱讀完整流程圖。

**目前進度：**
- 03｜諮詢階段：進行中
- 其他階段：陸續建置中

### ② AI 引導式流程知識庫（測試中）

**[開啟 ChatGPT 流程知識庫](https://chatgpt.com/g/g-p-6ae5890c932481919ec65821eb1615a7-fu-wu-lu-cheng-yu-liu-cheng-zhi-shi-ku/shared/c/6ae5953f-5ae4-83ec-b3c1-198bfe5f6787?owner_user_id=user-C9jHvF9v8LHbhzQLwyXqJlCQ)**

嘗試透過 AI 對話方式，引導使用者探索客戶旅程、理解服務流程，並針對流程內容提出問題與改善建議。

**測試方向：**
- 透過自然語言詢問流程相關問題。
- 由 AI 引導查找對應的流程與教學資料。
- 討論現有流程中的疑問、問題與改善方向。
- 蒐集使用者的操作體驗、意見及建議。

> ⚠️ 此功能仍處於測試階段，AI 回答可能不完整或有誤，實際作業仍應以正式規範及最新文件為準。請勿在對話中提供客戶個資或其他機密資訊。

## 🧭 專案目標

本專案希望逐步達成以下目標：

**流程視覺化**  
將服務流程轉換為容易理解的圖像，協助不同角色掌握工作內容與協作關係。

**教材集中化**  
建立流程節點與教學資料之間的連結，減少反覆搜尋文件的時間。

**學習自主化**  
讓使用者依照實際需求，自行探索流程、查找教材及理解應對方式。

**持續改善**  
透過實際使用與回饋，逐步修正流程內容、改善資訊架構與操作體驗。

## 🧪 專案狀態

**目前仍在建置與測試階段。**

部分流程、教材連結與 AI 引導功能尚未完成，內容將依測試結果持續調整。

歡迎實際操作兩個專案入口，並針對以下方向提供回饋：

- 流程內容是否容易理解？
- 是否能快速找到需要的資訊？
- 教材連結與操作方式是否直覺？
- 是否有遺漏、錯誤或需要補充的流程？
- AI 引導方式是否有助於理解與學習？

**歡迎提出問題、使用心得與改善建議，作為後續優化的參考。**
